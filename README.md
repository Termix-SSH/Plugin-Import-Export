## Overview

Import and Export moves your hosts in and out of Termix. Bring hosts in from a Termix JSON file or an SSH config file, and take them out again to back up or to share.

Read the [docs](https://docs.termix.site/plugins/import-export) to set it up and use it.

<br />

## Features

- Import hosts from a Termix JSON file
- Import hosts from an SSH config file
- Skip or overwrite hosts that already exist
- Export all or some hosts and pick which fields to include
- Share an export without any passwords or keys

## Support

Bugs and ideas for Import and Export go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Import-Export/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Import-Export/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
